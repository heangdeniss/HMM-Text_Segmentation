Under the hood

Three ideas make it work

A textbook HMM, engineered so that real-world text cannot break it.

01

Maximum-likelihood estimation

Initial, transition and emission distributions are counted directly from 45,872 training sentences over 12 universal tags. 

π(sᵢ) = count(start = sᵢ) / M
Aᵢⱼ   = count(sᵢ → sⱼ) / Σₖ count(sᵢ → sₖ)
02

Laplace smoothing + OOV mass

An explicit <OOV> slot keeps every unseen word decodable. A validation-only grid search selects α, avoiding test leakage. 

Bᵢ(w)   = (count(sᵢ, w) + α) / D
Bᵢ(OOV) = α / D
D       = count(sᵢ) + α(|V| + 1)
03

Log-space Viterbi

Products become sums, so long sentences cannot underflow to zero. A 10⁻¹² guard keeps impossible transitions finite. 

log vₜ(j) = maxᵢ [ log vₜ₋₁(i) + log(Aᵢⱼ + ε) ]
            + log(Bⱼ(oₜ) + ε)

Experimental results

Why α = 10⁻⁹ wins

Add-one smoothing (α = 1) injects enormous pseudo-mass into a 45k-word vocabulary. Sweeping α over eight orders of magnitude finds a sharp optimum on a held-out validation split.
