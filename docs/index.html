How it works

A standard HMM, engineered so real text cannot break it.

  1. 01

    Estimate the probabilities

    Initial, transition and emission distributions are counted directly from 45,872 training sentences over 12 universal tags.

    π(sᵢ) = count(start = sᵢ) / M   Aᵢⱼ = count(sᵢ → sⱼ) / Σₖ count(sᵢ → sₖ)

  2. 02

    Smooth the unseen words

    An explicit <OOV> bucket keeps every unknown word decodable. The smoothing constant is chosen on a validation split, so the test set stays untouched.

    Bᵢ(w) = (count(sᵢ, w) + α) / D   D = count(sᵢ) + α(|V| + 1)

  3. 03

    Decode in log space

    Viterbi products become sums, so long sentences never underflow to zero. The optimum is recovered with a single backpointer traceback.

    log vₜ(j) = maxᵢ [ log vₜ₋₁(i) + log(Aᵢⱼ + ε) ] + log(Bⱼ(oₜ) + ε)

Why α = 1e-9 wins

Add-one smoothing injects a large amount of pseudo-mass into a 45,000-word vocabulary. Sweeping α over eight orders of magnitude on a held-out validation split finds a sharp optimum at 1e-9.

96.05%

223,015 of 232,177 test tokens tagged correctly — a 36.3% relative error reduction over the add-one baseline (93.80%).
